# 设置全局一份存 localStorage，键位在运行时可变

键位、视距、灵敏度、三个画面开关是玩家的偏好，与哪个世界无关。前几个切片里它们全是编译期常量：键位表 `as const`，架构测试要求按键名只出现在键位文件里，视距只能在构造核心时传。

定为：**设置全局一份、不随世界，存 localStorage，不进存档也不进导出文件。** 键位表改为「默认值加当前值」的可变表，输入层每次按键查当前值；视距改为核心的可变属性，改小时立即卸载超出范围的区块；灵敏度与画面开关是渲染层与输入层读的变量。架构测试里「按键名只出现在键位文件」那条保留，设置界面显示按键名时从键位文件取显示名，不自己写字面量。

## Considered Options

- **随世界存进存档**：没有场景需要同一个玩家在两个世界里用不同的键位；导入别人的存档还会带来别人的键位。
- **存 IndexedDB 与存档同库**：多一次异步读，页面打开时世界列表要等它。设置总共几百字节，localStorage 同步读正好。

## Consequences

- 视距从 `readonly` 变成可改，区块流式加载的半径与渲染层的网格计划都要读当前值而不是构造时的值。
- 挖掘与使用固定在鼠标左右键、Esc 固定用于关闭，不进可改的范围：前两者改了与原版玩家的习惯冲突（ADR-0009、ADR-0015 的理由），Esc 是浏览器的约定。
- 两个动作绑到同一个键时不阻止保存，只标红提示；按下那个键时两个动作都触发。
