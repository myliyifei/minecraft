# 运行在浏览器中，使用 TypeScript + Three.js

这是一个体素生存沙盒，需要无限地形、区块流式加载与原版式流体，性能压力不小，直觉上会选原生（Rust + wgpu）或现成引擎。我们仍选择浏览器 + TypeScript + Three.js：体素游戏的核心难点是区块网格生成与地形算法，与平台无关；浏览器方案迭代最快、双击即玩、便于分享，且地形生成与网格构建可放入 Web Worker 摊平主线程压力。性能目标定为桌面 Chrome、默认 8 区块视距、60fps。

## Considered Options

- **Rust + wgpu 原生**：性能上限最高，但开发周期明显更长，分享需要打包分发。
- **Godot / Unity**：体素网格合并仍需自写，引擎对这类游戏帮助有限，还要承担引擎学习与许可成本。

## Consequences

- 存档落在浏览器本地存储中，因此需要导出/导入文件作为备份路径。
- 美术与音效必须使用 CC0 或同类自由许可素材，不能使用原版资源。
- 世界状态与渲染层保持分离，若日后性能触顶，逻辑层可迁移到其他平台或迁入 Worker。
